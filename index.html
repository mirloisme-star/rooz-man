Google Calendar

One-time setup (about 10 minutes)

My Day writes into its own calendar called "My Day", so your other calendars stay untouched. You can hide or colour it in Google Calendar like any other calendar. Google Cloud may need a VPN from Iran.

  1. Open console.cloud.google.com and create a project named My Day.
  2. APIs & Services → Library → enable Google Calendar API.
  3. APIs & Services → OAuth consent screen → External. App name My Day, then add your own Google account as a test user.
  4. Under Data access, add the scopes …/auth/calendar.app.created and …/auth/calendar.calendarlist.readonly.
  5. Credentials → Create credentials → OAuth client ID → Web application. Under Authorized JavaScript origins add https://mirloisme-star.github.io.
  6. Copy the Client ID, paste it below, then press Connect. A Client ID is not a secret.
